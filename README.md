# QSentinel

QSentinel is an experimental intelligent Windows resource orchestrator.

## Architecture

QSentinel combines:

- Windows background monitoring
- process classification
- resource-pressure analysis
- safety-first intervention
- reversible optimization
- classical optimization
- hybrid quantum/classical research
- reproducible benchmarking

## Safety principle

No quantum or optimization algorithm has direct authority over Windows processes.

All proposed interventions must pass through the QSentinel Safety Engine.
