# QSentinel V1 Architecture

## QSentinel.Desktop
Windows user interface and telemetry visualization.

## QSentinel.Agent
Low-overhead background Windows service.

## QSentinel.Core
Shared models, telemetry and policy contracts.

## QSentinel.Safety
Final authority over every proposed intervention.

## QSentinel.Optimizer
Local classical decision engine.

## Quantum Lab
Experimental hybrid quantum/classical optimization research.

## Simulator
Generates controlled process/resource scenarios without risking a real Windows installation.

## Principle

Optimizer -> Recommendation -> Safety Engine -> Decision -> Windows

Never:

Optimizer -> Windows
