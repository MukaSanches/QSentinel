# QSentinel V1 Windows

## Current implementation

- Native Windows desktop application
- Runs in the notification area
- Live process monitoring
- Physical memory monitoring
- Protected-process Safety Engine
- Observation-first design
- Manual termination with confirmation
- Memory usage ranking
- High-usage classification
- Single-instance protection
- Windows x64 self-contained build
- GitHub Actions build pipeline

## Safety

Automatic process termination is intentionally disabled at this stage.

Before autonomous intervention is enabled, QSentinel requires
additional Windows-specific regression and recovery testing.

## Quantum

The quantum research layer remains isolated from the Windows
execution authority. Quantum results are advisory only.
